# 01 — Основы ISA

Канон: [isa/spec.md](../isa/spec.md).

## Модель

- **Слово:** 32 бита, little-endian в памяти.
- **GPR:** `r0`…`r31`. `r0` при чтении всегда **0** (запись игнорируется).
- **ABI:** `r30` = SP, `r31` = PC (IP).
- **PC:** после инструкции без явного перехода → `PC + 4`.

## Флаги (младшие биты слова `flags`)


| Бит | Имя       | Смысл                            |
| --- | --------- | -------------------------------- |
| 0   | Intenable | Прерывания разрешены (`EI`/`DI`) |
| 1   | Zero      | Z                                |
| 2   | Carry     | C (беззнаковый перенос/заём)     |
| 3   | Overflow  | V (знаковое переполнение)        |
| 4   | Sign      | S (бит 31 результата)            |


`ADD`/`SUB` без суффикса **S** флаги не меняют. `ADDS`/`SUBS` — знаковая арифметика с обновлением Z,C,V,S.

## Память

`LDR`/`STR` — только **выровненные** адреса (`addr % 4 == 0`), иначе `MisalignedAccess`.

Поле **mask** (5 бит): бит `k` — байт `k` слова (0 = младший).

## Особые слова


| Слово | Значение                   |
| ----- | -------------------------- |
| NOP   | `0x00000000`               |
| HALT  | `0xFFFFFFFF` — останов CPU |


## NOP / HALT


| Мнемоника | Синтаксис | Эффект        |
| --------- | --------- | ------------- |
| NOP       | `NOP`     | Нет операции  |
| HALT      | `HALT`    | `halted=true` |

Поле **opcode** в битах `[31:26]`. Остальные поля — `R1`, `R2`, `Res`, `imm`, `mask` — см. таблицу в [spec.md](../isa/spec.md).
