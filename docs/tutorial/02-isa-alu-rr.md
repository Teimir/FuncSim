# 02 — АЛУ (формат rrr)

Синтаксис: `MNEMONIC r1 r2 res` (три номера регистра 0…31).

Lab: [asm/lab_alu.asm](asm/lab_alu.asm)

```bash
python -m cli.sim --asm docs/tutorial/asm/lab_alu.asm --until-halt --dump-regs
```

## Без обновления флагов


| Мнемоника | Семантика                 |
| --------- | ------------------------- |
| **ADD**   | `res = u32(r1) + u32(r2)` |
| **SUB**   | `res = u32(r1) - u32(r2)` |
| **AND**   | `res = u32(r1) & u32(r2)` |
| **OR**    | `res = u32(r1) | u32(r2)` |
| **XOR**   | `res = u32(r1) ^ u32(r2)` |


Пример:

```asm
ADDI 0 1 10
ADDI 0 2 3
ADD 1 2 3
```

## С обновлением флагов (знаковая семантика)


| Мнемоника | Семантика                    |
| --------- | ---------------------------- |
| **ADDS**  | Знаковое сложение → Z,C,V,S  |
| **SUBS**  | Знаковое вычитание → Z,C,V,S |
| **ANDS**  | Логическое И → Z,S; C=V=0    |


Псевдо **CMP** `r1 r2` → `SUBS r1 r2 0` (результат в r0 не используется).

## Сдвиги (величина = `r2 & 0x1F`)


| Мнемоника | Семантика          |
| --------- | ------------------ |
| **SLL**   | Логический влево   |
| **SLR**   | Логический вправо  |
| **SAL**   | В модели = SLL     |
| **ROL**   | Циклический влево  |
| **ROR**   | Циклический вправо |


## Битовые примитивы


| Мнемоника | Семантика                             |
| --------- | ------------------------------------- |
| **BIC**   | `res = u32(r1) & ~u32(r2)`            |
| **MVN**   | `res = ~u32(r2)` (r1 не используется) |
| **NEG**   | `res = (-s32(r2)) & 0xFFFFFFFF`       |


## С переносом (входной C из флага Carry)


| Мнемоника | Семантика                                  |
| --------- | ------------------------------------------ |
| **ADC**   | `res = u32(r1)+u32(r2)+C`                  |
| **ADCS**  | Как ADC + обновление Z,C,V,S               |
| **SBC**   | `res = u32(r1)-u32(r2)-NOT(C)` (ARM-стиль) |
| **SBCS**  | Как SBC + флаги                            |


Пример цепочки с переносом:

```asm
ADDI 0 1 0xFFFFFFFF
ADDI 0 2 1
ADDS 1 2 0
ADC 1 2 3
```

## SMUL


| Мнемоника | Синтаксис        | Семантика                         |
| --------- | ---------------- | --------------------------------- |
| **SMUL**  | `SMUL r1 r2 res` | Младшие 32 бита `s32(r1)*s32(r2)` |
