# E32C ISA — функциональная спецификация (модель на Python)

Документ фиксирует семантику для **функционального интерпретатора** (без тактов/пайплайна). Неоднозначности со скриншота устранены явными правилами ниже.

## Общие положения

- **Ширина слова и регистров:** 32 бита, беззнаковая интерпретация в памяти; арифметика с переполнением по модулю 2³² для операций без флагов.
- **Регистры:** 32 GPR, индексы 0…31.
  - **R0:** при чтении всегда **0** (запись в R0 игнорируется).
  - **R31:** **IP** (instruction pointer / PC). После исполнения инструкции, если IP не был изменён явно, **IP ← IP + 4** (последовательное исполнение).
- **Память:** байтовая, адресация **little-endian**, выравнивание **не требуется** для модели; `LDR`/`STR` работают с **32-битным словом** по адресу `effective_address` (должен быть кратен 4; иначе — исключение).
- **Флаги** (младшие биты **словесного** поля `flags`, не отдельный SPR в этой модели):  
  - бит 0: **Intenable**  
  - бит 1: **Zero**  
  - бит 2: **Carry**  
  - бит 3: **Overflow**  
  - бит 4: **Sign**  

`EI` / `DI` устанавливают/сбрасывают только **Intenable**; остальные биты флагов не трогают.

## Кодировка полей (биты [31:0], MSB = 31)

| Поле   | Биты    | Описание |
|--------|---------|----------|
| opcode | [31:26] | Основной код операции (6 бит) |
| R1     | [25:21] | Регистр (источник/приёмник в зависимости от формата) |
| R2     | [20:16] | Второй источник |
| Res    | [15:11] | Результат |
| mask   | [15:11] | Маска байтов для LDR/STR |
| IMMH   | [20:16] | Старшая часть немедленного операнда (ADDI/SUBI) |
| imm    | [10:0]  | 11-битное поле (смещение / младшая часть IMM) |
| Raddr  | [25:21] | Базовый регистр адреса |
| Rdata  | [20:16] | Регистр данных для STR |
| ResH   | [10:6]  | Регистр старших 32 бит произведения (MUL) |
| SPR    | [15:11] | Индекс SPR для READSPR |

## Немедленные значения

- **ADDI / SUBI:** 16-битное значение  
  `imm16 = ((IMMH << 11) | imm) & 0xFFFF`, далее **знаковое расширение** до 32 бит (как signed 16-bit).
- **LDR / STR / Jcc / JMP:** `imm11 = imm` трактуется как **знаковое 11-битное** значение: расширить до 32 бит.

## Эффективный адрес памяти

- **LDR:** `EA = R[Raddr] + imm11` (32-битное сложение с усечением). Регистр назначения **`Rdest` закодирован в [20:16]** (в исходной таблице явно не назван; принято по аналогии со STR).
- **STR:** `EA = R[Raddr] + imm11`.

## Маска LDR/STR

Поле `mask` (5 бит): бит `k` (k = 0…4) соответствует **байту k** слова по адресу EA (младший байт слова — байт 0).

- **LDR:** прочитать 32-битное слово `W` из памяти по EA. В **`R[Rdest]`** записать: начать с 0; для каждого `k`, если `mask & (1<<k)`, установить байт `k` результата равным байту `k` из `W`; если бит маски сброшен, байт `k` результата **0**.
- **STR:** взять значение `V` из `R[Rdata]`. Сформировать слово для записи: прочитать текущее `W` по EA (RMW), затем для каждого `k`, если `mask & (1<<k)`, заменить байт `k` в `W` байтом `k` из `V`; записать `W` обратно.

Если `mask == 0`, **LDR** записывает 0; **STR** не изменяет память (no-op для памяти).

## АЛУ и флаги

- **ADD, SUB, AND, OR, XOR, SLL, SLR, SAL, MUL, ADDI, SUBI:** флаги **Z/C/V/S не обновляют** (кроме перечисленного ниже для MUL — не обновляет).
- **ADDS:** `res = R1 + R2` (mod 2³²).  
  - **Carry:** перенос из бита 31 (unsigned overflow 32-bit).  
  - **Overflow:** signed overflow для 32-bit signed.  
  - **Zero:** `res == 0`.  
  - **Sign:** бит 31 `res`.
- **SUBS:** `res = R1 - R2` (mod 2³²).  
  - **Carry:** заём при unsigned вычитании (`R1 >= R2` как unsigned → Carry=1, иначе 0) — стандартная ARM-подобная семантика «Carry = NOT borrow».  
  - **Overflow:** signed overflow вычитания.  
  - **Zero / Sign:** как у ADDS.

**SLL / SLR / SAL:** величина сдвига = `R[R2] & 0x1F` (младшие 5 бит).  
- **SLL:** логический влево.  
- **SLR:** логический вправо.  
- **SAL:** «арифметический влево» в данной модели **идентичен SLL** (явное допущение; на некоторых ISA SAL = SLA).

**MUL:** `prod = u32(R1) * u32(R2)` как 64-битное беззнаковое произведение.  
- `R[Res] = prod & 0xFFFFFFFF`  
- `R[ResH] = (prod >> 32) & 0xFFFFFFFF`

## Переходы

База: `base = R[Raddr]`, цель: `target = base + imm11` (32-bit wrap).

- **JMP:** `IP ← target` (без условий).
- **JZ:** если **Zero** установлен → `IP ← target`, иначе `IP ← IP + 4`.
- **JNZ:** если **Zero** сброшен → `IP ← target`, иначе `IP ← IP + 4`.
- **JC:** если **Carry** установлен → `IP ← target`, иначе `IP ← IP + 4`.
- **JS:** если **Sign** установлен → `IP ← target`, иначе `IP ← IP + 4`.
- **JO:** если **Overflow** установлен → `IP ← target`, иначе `IP ← IP + 4`.

После любого взятого перехода **не** добавлять +4 вторично в том же шаге (исполнитель задаёт новый IP явно).

## Системные инструкции

- **NOP:** слово == 0; нет эффектов.
- **HALT:** слово == `0xFFFFFFFF`; `halted ← true`, исполнение останавливается.
- **EI / DI:** установить/сбросить **Intenable** (бит 0 поля флагов).
- **IRET:** код операции `111110` ([31:26]); восстановить **IP** из сохранённого значения прерывания: `IP ← cpu.saved_irq_pc` (см. SPR и модель прерываний ниже). Остальные биты инструкции игнорируются.
- **READSPR:** `R[R1] ← SPR[SPR]`, где `R1` — индекс регистра назначения из поля [25:21], `SPR` — индекс из [15:11]. Запись в R0 подавляется.

## SPR (специальные регистры)

Минимальный набор для тестируемости:

| Индекс | Имя        | Описание |
|--------|------------|----------|
| 0      | SAVED_IRQ_PC | Адрес возврата из прерывания; пишется моделью при входе в IRQ (см. ниже) |
| 1      | IRQ_VECTOR   | Базовый адрес обработчика (младшие 32 бита) |

**Модель прерывания (упрощённо):** если `Intenable` и вызывается `cpu.raise_irq(return_pc)`, то  
`SPR[SAVED_IRQ_PC] ← return_pc`, `IP ← SPR[IRQ_VECTOR]` (чтение SPR напрямую из банка).  
В базовых тестах IRQ может не вызываться; **IRET** читает `saved_irq_pc` из SPR[0].

## Особые слова

- **NOP:** `0x00000000`
- **HALT:** `0xFFFFFFFF`

## Исключения модели

- Невыровненный доступ **LDR/STR** (EA % 4 != 0): `MisalignedAccess`.
- Неизвестный opcode: `IllegalInstruction`.
- Обращение к несуществующей странице памяти (если память ограничена): `MemoryError` (опционально; по умолчанию память расширяется нулями или фиксированного размера — см. реализацию).
