# E32C ISA — функциональная спецификация (модель на Python)

Документ фиксирует семантику для **функционального интерпретатора** (без тактов/пайплайна). Неоднозначности со скриншота устранены явными правилами ниже.

## Общие положения

- **Ширина слова и регистров:** 32 бита, беззнаковая интерпретация в памяти; арифметика с переполнением по модулю 2³² для операций без флагов.
- **Регистры:** 32 GPR, индексы 0…31.
  - **R0:** при чтении всегда **0** (запись в R0 игнорируется).
  - **R30:** по соглашению ABI — **SP** (stack pointer); аппаратно это обычный GPR, без отдельного стекового порта.
  - **R31:** **IP** (instruction pointer / PC). После исполнения инструкции, если IP не был изменён явно, **IP ← IP + 4** (последовательное исполнение).
- **Память:** байтовая, адресация **little-endian**, выравнивание **не требуется** для модели; `LDR`/`STR` работают с **32-битным словом** по адресу `effective_address` (должен быть кратен 4; иначе — исключение).
- **Флаги** (младшие биты **словесного** поля `flags`, не отдельный SPR в этой модели):  
  - бит 0: **Intenable**  
  - бит 1: **Zero**  
  - бит 2: **Carry**  
  - бит 3: **Overflow**  
  - бит 4: **Sign**

`EI` / `DI` устанавливают/сбрасывают только **Intenable**; остальные биты флагов не трогают.

## Кодировка полей (биты [31:0], MSB = 31)


| Поле   | Биты    | Описание                                             |
| ------ | ------- | ---------------------------------------------------- |
| opcode | [31:26] | Основной код операции (6 бит)                        |
| R1     | [25:21] | Регистр (источник/приёмник в зависимости от формата) |
| R2     | [20:16] | Второй источник                                      |
| Res    | [15:11] | Результат                                            |
| mask   | [15:11] | Маска байтов для LDR/STR                             |
| IMMH   | [20:16] | Старшая часть немедленного операнда (ADDI/SUBI)      |
| imm    | [10:0]  | 11-битное поле (смещение / младшая часть IMM)        |
| Raddr  | [25:21] | Базовый регистр адреса                               |
| Rdata  | [20:16] | Регистр данных для STR                               |
| ResH   | [10:6]  | Регистр старших 32 бит произведения (MUL)            |
| SPR    | [15:11] | Индекс SPR для READSPR                               |


## Немедленные значения

- **ADDI / SUBI:** 16-битное значение  
`imm16 = ((IMMH << 11) | imm) & 0xFFFF`, далее **знаковое расширение** до 32 бит (как signed 16-bit).
- **LDR / STR / Jcc / JMP:** `imm11 = imm` трактуется как **знаковое 11-битное** значение: расширить до 32 бит.

## Эффективный адрес памяти

- **LDR:** `EA = R[Raddr] + imm11` (32-битное сложение с усечением). Регистр назначения `**Rdest` закодирован в [20:16]** (в исходной таблице явно не назван; принято по аналогии со STR).
- **STR:** `EA = R[Raddr] + imm11`.

## Маска LDR/STR

Поле `mask` (5 бит): бит `k` (k = 0…4) соответствует **байту k** слова по адресу EA (младший байт слова — байт 0).

- **LDR:** прочитать 32-битное слово `W` из памяти по EA. В `**R[Rdest]`** записать: начать с 0; для каждого `k`, если `mask & (1<<k)`, установить байт `k` результата равным байту `k` из `W`; если бит маски сброшен, байт `k` результата **0**.
- **STR:** взять значение `V` из `R[Rdata]`. Сформировать слово для записи: прочитать текущее `W` по EA (RMW), затем для каждого `k`, если `mask & (1<<k)`, заменить байт `k` в `W` байтом `k` из `V`; записать `W` обратно.

Если `mask == 0`, **LDR** записывает 0; **STR** не изменяет память (no-op для памяти).

## АЛУ и флаги

- **ADD, SUB, AND, OR, XOR, SLL, SLR, SAL, ROL, ROR, SMUL, MUL, ADDI, SUBI:** флаги **Z/C/V/S не обновляют** (**MUL** / **UMULL** / **SMULL** тоже).

### ADDS / SUBS — знаковая (two’s complement) арифметика

Операнды **R1** и **R2** трактуются как **знаковые 32-битные** целые. Результат записывается как младшие 32 бит суммы/разности в бесконечной точности (то есть по правилам дополнения до двух с усечением по модулю 2³²). Суффикс **S** означает обновление флагов **после этой знаковой операции**, а не «отдельное включение флагов».

- **ADDS:** пусть `s32(x)` — знаковое значение слова `x`. Тогда математическая сумма `S = s32(R1) + s32(R2)`, в регистр результата пишется `res = S & 0xFFFFFFFF`.  
  - **Z:** `res == 0`.  
  - **S (Sign):** бит 31 `res` (знак усечённого результата).  
  - **V (Overflow):** `S` не попадает в диапазон signed 32-bit `[−2³¹, 2³¹−1]`.  
  - **C (Carry):** перенос при **беззнаковом** сложении `u32(R1) + u32(R2)` (бит переноса за 31-й разряд), как в ARM.
- **SUBS:** `D = s32(R1) − s32(R2)`, `res = D & 0xFFFFFFFF`.  
  - **Z / S:** как у ADDS от `res`.  
  - **V:** `D` вне диапазона signed 32-bit.  
  - **C:** **нет заёма** при беззнаковом вычитании (`u32(R1) ≥ u32(R2)` → C=1), семантика «Carry = NOT borrow» (ARM).

**SLL / SLR / SAL / ROL / ROR:** величина сдвига = `R[R2] & 0x1F` (младшие 5 бит; при 0 сдвиг — тождественное преобразование).  

- **SLL:** логический влево (младшие биты заполняются нулями).  
- **SLR:** логический вправо.  
- **SAL:** «арифметический влево» в данной модели **идентичен SLL** (явное допущение; на некоторых ISA SAL = SLA).
- **ROL / ROR:** **циклический** сдвиг влево / вправо по 32 битам (биты, выходящие за край, заносятся с противоположной стороны).

**MUL / UMULL:** `prod = u32(R1) * u32(R2)` как 64-битное беззнаковое произведение (`UMULL` — то же по смыслу; **MUL** сохранён для совместимости).

- `R[Res] = prod & 0xFFFFFFFF`  
- `R[ResH] = (prod >> 32) & 0xFFFFFFFF`

**SMULL:** `prod = s32(R1) * s32(R2)` (знаковое 32×32→64 в дополнении до двух).

**SMUL:** только младшие 32 бита знакового произведения: `R[Res] = (s32(R1) * s32(R2)) & 0xFFFFFFFF` (удобно, когда полный 64-битный результат не нужен; совпадает с младшей половиной **SMULL**).

**MLA:** `R[Res] = (u32(R1)*u32(R2) + u32(Racc)) & 0xFFFFFFFF` (младшие 32 бит суммы; переполнение отбрасывается).

**ADC / ADCS:** `res = u32(R1) + u32(R2) + C` (входной перенос **C** — флаг Carry: 0 или 1). **ADCS** обновляет Z,C,V,S по знаковой/беззнаковой семантике, аналогично **ADDS** с третьим слагаемым **C**.

**SBC / SBCS:** `res = u32(R1) - u32(R2) - NOT(C)` (как в ARM: при **C=1** вычитается 0 дополнительно, при **C=0** — единица). **SBCS** обновляет флаги.

**BIC / MVN / NEG:** одна форма **rrr** (три поля регистров, как у **ADD**): без отдельных «спец» форматов в декодере — это базовые битовые и знаковые примитивы. **BIC:** `res = u32(R1) & ~u32(R2)`. **MVN:** `res = ~u32(R2)` (поле R1 не используется). **NEG:** `res = (-s32(R2)) & 0xFFFFFFFF`.

**ANDS:** логическое И + обновление Z,S; **C=V=0** (логические флаги без сдвигателя).

**ADDSI / SUBSI:** как **ADDI**/**SUBI**, но с обновлением Z,C,V,S по правилам **ADDS**/**SUBS** (немедленник знаково расширяется до 32 бит).

## Доступ к памяти (расширения)

- **LDRPOST:** `EA = R[Raddr]`; загрузка как у **LDR**; затем `R[Raddr] ← R[Raddr] + imm11` (постиндексация, удобно для обхода массива / обновления указателя).
- **STRPOST:** `EA = R[Raddr]`; запись как у **STR**; затем `R[Raddr] ← R[Raddr] + imm11`.

## Переходы

База: `base = R[Raddr]`, цель: `target = base + imm11` (32-bit wrap).

- **JMP:** `IP ← target` (без условий).
- **JZ / JNZ / JC / JS / JO:** как раньше по одному флагу.
- **BJ** (в дизассемблере — **BEQ**, **BNE**, …): 4-битное поле условия **cond** (см. таблицу ниже). Если условие выполняется, `IP ← target`, иначе `IP ← IP + 4`.


| cond | Мнемоника | Условие                   |
| ---- | --------- | ------------------------- |
| 0    | EQ        | Z                         |
| 1    | NE        | ¬Z                        |
| 2    | CS/HS     | C                         |
| 3    | CC/LO     | ¬C                        |
| 4    | MI        | S                         |
| 5    | PL        | ¬S                        |
| 6    | VS        | V                         |
| 7    | VC        | ¬V                        |
| 8    | HI        | C∧¬Z                      |
| 9    | LS        | ¬C∨Z                      |
| 10   | GE        | S=V                       |
| 11   | LT        | S≠V                       |
| 12   | GT        | ¬Z∧(S=V)                  |
| 13   | LE        | Z∨(S≠V)                   |
| 14   | AL        | всегда                    |
| 15   | NV        | никогда (зарезервировано) |


В ассемблере можно писать **BEQ**, **BNE**, … — они кодируются как **BJ** с нужным **cond**.

После любого взятого перехода **не** добавлять +4 вторично в том же шаге.

## Псевдо-инструкции ассемблера

Не занимают отдельных опкодов:

- **CMP r1 r2** → **SUBS r1 r2 0** (сравнение как вычитание; флаги от `s32(r1)−s32(r2)`, результат в R0 не используется).
- **CMN r1 r2** → **ADDS r1 r2 0** (сравнение как сложение; флаги от `s32(r1)+s32(r2)`, эквивалентно проверке `r1 − (−r2)`; результат в R0 не используется).
- **TST** / **TEST r1 r2** → **ANDS r1 r2 0**.
- **MOV** / **MOVI dst imm** → **ADDI 0 dst imm**.

## Системные инструкции

- **NOP:** слово == 0; нет эффектов.
- **HALT:** слово == `0xFFFFFFFF`; `halted ← true`, исполнение останавливается.
- **EI / DI:** установить/сбросить **Intenable** (бит 0 поля флагов).
- **IRET:** восстановить **IP** из **SPR[SAVED_IRQ_PC]**.
- **READSPR:** `R[R1] ← SPR[SPR]`. Запись в R0 подавляется.
- **WRITESPR:** `SPR[SPR] ← R[R1]` (чтение R1 с учётом правил R0).

## SPR (специальные регистры)


| Индекс | Имя          | Описание                                                                                                                                      |
| ------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 0      | SAVED_IRQ_PC | Адрес возврата из прерывания                                                                                                                  |
| 1      | IRQ_VECTOR   | Вектор обработчика (младшие 32 бита)                                                                                                          |
| 2      | IRQ_MASK     | Бит `i` = 1: линия прерывания `i` **замаскирована** (не доставляется). Значение по умолчанию при отсутствии записи — 0 (все линии разрешены). |


**Модель прерывания (RTL `csr_irq`):** линия таймера (0) — **уровневая** (`irq_enable && irq_pending`). Пока обработчик не завершён, **`in_service`** блокирует повторный вход; **IRET** сбрасывает `in_service` и восстанавливает **IP** из **SPR[SAVED_IRQ_PC]**. В FETCH при `irq_pending` ядро переходит на **SPR[IRQ_VECTOR]** и фиксирует **SAVED_IRQ_PC ← IP** (адрес прерыдённой инструкции). Симулятор Python: `raise_irq(return_pc, line)` при **Intenable**, маске и `not irq_in_service`; **IRET** сбрасывает `irq_in_service`.

## Особые слова

- **NOP:** `0x00000000`
- **HALT:** `0xFFFFFFFF`

## Исключения модели

- Невыровненный доступ **LDR/STR** (EA % 4 != 0): `MisalignedAccess`.
- Неизвестный opcode: `IllegalInstruction`.
- Обращение к несуществующей странице памяти (если память ограничена): см. реализацию `Memory` / `SystemBus`.

## Расширения памяти (реализовано в функциональной модели)

- **LDRPRE / STRPRE:** `R[raddr] ← R[raddr] + imm`, затем load/store по обновлённому базовому адресу.
- **LDREX / STREX:** упрощённый монитор эксклюзивного доступа (`CPUState.exclusive_*`); **STREX** `raddr rsrc rstatus imm` — при успехе записывает `rsrc` в память и `rstatus←0`, иначе `rstatus←1`.
- **PUSH / POP** в ассемблере — псевдо-операции (разворачиваются в **SUBI**/**STRPOST** и **LDRPOST**/**ADDI** на **R30**).
